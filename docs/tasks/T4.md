# T4 — 인게임 저장과 설정 메뉴

## 목표

인게임 화면을 대사 진행과 명시적 저장에 집중시키고, 우측 상단 설정 메뉴에서 나가기와
게임 설정을 제공한다.

## 포함 범위

- 인게임 하단에서 이전·다음·불러오기·타이틀 버튼 제거
- 대사 진행은 클릭 또는 키보드, 저장은 단일 `저장` 버튼으로 유지
- 우측 상단 `설정` → `나가기` / `게임 설정` 메뉴
- 나가기 시 타이틀 화면 복귀
- 실제 적용되는 대사 글자 크기와 대사창 투명도 설정

## 완료 정의

- [ ] 인게임에 저장 버튼만 표시된다
- [ ] 나가기가 타이틀로 돌아간다
- [ ] 게임 설정이 저장되고 대사창에 반영된다
- [ ] EditMode 전체 게이트 통과

## Non-scope

- 불러오기 화면, 다중 저장 슬롯, 오디오 설정
