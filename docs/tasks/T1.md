# T1 — 비주얼 노벨 기반 화면

## 목표

보관함의 초기 기획을 실제 Unity 플레이 화면으로 옮긴다. 플레이어가 선형 프롤로그를
읽고, 진행도를 저장하거나 불러올 수 있어야 한다.

## 포함 범위

- 엔진 비의존 스토리 시퀀스와 진행 상태 모델
- 회사의 독가스 사건으로 시작하는 한국어 프롤로그 8문장
- 런타임 생성형 비주얼 노벨 UI: 다음, 이전, 저장, 불러오기, 처음부터
- 빈 씬에서도 실행되는 부트스트랩과 빌드용 씬 등록

## 완료 정의

- [ ] EditMode 전체 게이트 통과
- [ ] 같은 조작 순서에서 스토리 진행 상태가 항상 같다
- [ ] 실행 빌드에 `VisualNovel` 씬이 포함된다
- [ ] 저장 후 재실행 또는 불러오기로 같은 대사가 열린다

## Non-scope

- 분기, 전투, 맵 탐색, 캐릭터 초상화, 음성, 에셋 조달
- 최종 장르·아트 디렉션·정식 시나리오의 확정
