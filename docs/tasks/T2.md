# T2 — 타이틀 화면과 저장 진입점

## 목표

게임 실행 직후 타이틀 화면을 표시하고, 플레이어가 새 게임·저장된 게임·보관함·설정으로
명확하게 진입할 수 있게 한다.

## 포함 범위

- 일러스트 교체 전 사용할 코드 기반의 임시 도시·사무실 실루엣 배경
- 좌측 하단의 `처음부터`, `이어하기`, `보관함`, `설정` 메뉴
- 명시적 저장만 이어하기에 사용하도록 PlayerPrefs 저장 흐름 정리
- 보관함의 저장 진행 확인과 프롤로그 대사 열람
- 설정의 대사 글자 크기 조절

## 완료 정의

- [ ] 실행 시 타이틀 화면이 먼저 표시된다
- [ ] 처음부터가 첫 대사부터 게임 화면을 연다
- [ ] 게임 내 저장 뒤 이어하기가 같은 대사를 연다
- [ ] 보관함과 설정에서 타이틀로 돌아올 수 있다
- [ ] EditMode 전체 게이트 통과

## Non-scope

- 최종 일러스트·캐릭터 초상화·음성·BGM
- 다중 저장 슬롯과 분기 시나리오
