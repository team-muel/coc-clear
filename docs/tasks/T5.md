# T5 — 사용자 제공 타이틀 일러스트

## 목표

사용자가 제공한 체인·산 풍경 일러스트를 게임의 타이틀 화면 배경으로 사용한다.

## 포함 범위

- `TitleBackground.png`를 Unity Resources와 보관함 갤러리에 등록
- 타이틀 화면에서 비율을 유지한 전체 배경 표시와 메뉴 가독성 오버레이
- 라이선스 대장에 사용자 제공 권한 기록

## 완료 정의

- [ ] 타이틀 화면이 제공 일러스트를 배경으로 표시한다
- [ ] 같은 이미지는 보관함 일러스트 갤러리에도 전시된다
- [ ] EditMode 전체 게이트 통과

## Non-scope

- 이미지 리터칭, 크롭 원본 변경, 외부 배포
