# T3 — 보관함 콘텐츠 라이브러리

## 목표

보관함에서 저장 진행, 모든 등록 시나리오 기록, 그리고 전달받은 게임 일러스트를 한곳에서
열람한다.

## 포함 범위

- `ScenarioArchive` 중앙 목록으로 시나리오 기록 렌더링
- 보관함의 시나리오 기록 / 일러스트 탭
- `Assets/CocClear/Resources/Archive/`의 모든 텍스처를 자동 전시하는 갤러리
- 이후 전달되는 일러스트의 임포트 위치·라이선스 규칙 문서화

## 완료 정의

- [ ] 저장 진행과 프롤로그 모든 대사가 보관함에 표시된다
- [ ] 이후 추가하는 시나리오 기록은 `ScenarioArchive`에 등록해 표시할 수 있다
- [ ] 전시 폴더의 텍스처가 갤러리에 모두 표시된다
- [ ] EditMode 전체 게이트 통과

## Non-scope

- CG 잠금 해제 조건, 확대 보기, 다중 저장 슬롯
- 외부 일러스트 생성 또는 라이선스 없는 이미지 임포트
