## Rules

- **CC0** (Poly Haven, ambientCG, Kenney, Quaternius): free to use, still gets a row.
- **Per-asset licenses** (Freesound, OpenGameArt, Mixamo, Asset Store): verify before commit. Some are per-file, not per-pack.
- **Fonts**: OFL is not CC0. Ship the LICENSE file alongside.
- **AI-generated**: record the model, the prompt source, and the provider's terms.
