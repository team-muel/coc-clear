# 비주얼 노벨 UX용 UI 일러스트 보고서

작성일: 2026-07-30

## 현재 구현 범위

현재 게임은 텍스트 버튼과 코드로 생성한 둥근 패널만으로 다음 UX를 제공한다.

- 글자 단위 대사 출력, 자동 진행, 스킵, 대사 로그
- 빠른 저장, UI 숨김, 키보드 단축키
- 글자 크기·출력 속도·자동 진행 시간·대사창 투명도 설정

따라서 아래 일러스트는 현 단계의 기능 완성에 필요한 조건이 아니라, 다음 시각적 완성도 단계에서 추가할 자산이다.

## 우선순위 A — 가장 효과가 큰 자산

| 자산 | 권장 규격 | 쓰임 | 필요한 변형 |
| --- | --- | --- | --- |
| 대화 조작 아이콘 세트 | 48×48px PNG, 투명 배경 | `LOG`, `AUTO`, `SKIP`, `SAVE`, 설정 텍스트 버튼 대체 | 기본·호버·활성 3종 |
| 저장 슬롯 프레임 | 560×132px PNG 또는 9-slice | 추후 다중 저장 슬롯의 공통 테두리 | 비어 있음·저장됨·선택·잠금 |
| 대사창 장식 코너 | 96×96px PNG, 투명 배경 | 현재 코드 패널의 모서리와 화자 바를 고급화 | 밝은/어두운 2색 |

## 우선순위 B — 분위기 강화 자산

| 자산 | 권장 규격 | 쓰임 |
| --- | --- | --- |
| 화자 이름판 배지 | 320×72px PNG, 투명 배경 | 화자명 왼쪽의 색상 구분과 소속 표현 |
| 대사 로그 헤더 장식 | 940×72px PNG, 투명 배경 | 로그 화면의 제목 영역을 단순 패널보다 명확하게 구분 |
| 상태 전환 마크 | 96×96px PNG, 투명 배경 | 자동 진행·스킵·저장 완료를 짧게 피드백할 때 사용 |

## 우선순위 C — 후반 확장용 자산

| 자산 | 권장 규격 | 쓰임 |
| --- | --- | --- |
| 챕터 카드 프레임 | 640×360px PNG 또는 9-slice | 보관함에서 챕터별 로그를 카드로 구분 |
| 선택지 버튼 프레임 | 760×96px PNG 또는 9-slice | 분기 선택지가 도입될 때 사용 |
| 시스템 메뉴 배경 패턴 | 1920×1080px PNG | 설정·로그·저장 화면의 단색 배경 보강 |

## 제작 가이드

- 모든 아이콘과 프레임은 원본 PNG와 투명 배경으로 보관한다.
- 텍스트·로고·타 게임의 고유 문양은 자산에 포함하지 않는다. 게임 안에서 텍스트는 별도로 렌더링한다.
- 모서리 프레임과 슬롯 프레임은 9-slice가 가능한 형태로 제작해 해상도 변화에 대응한다.
- 기본 색상은 현재 UI의 먹색·청록 포인트·은은한 주황 포인트를 따르되, 캐릭터와 배경보다 먼저 눈에 띄지 않게 한다.
