# Archive Illustration Gallery

Put every user-supplied illustration for the game in this folder (`png`, `jpg`, or other Unity-importable texture).
At startup, the title screen's **보관함 → 일러스트** tab loads every texture in this folder and displays it as a gallery item.

- Keep filenames meaningful; the filename is shown beneath each image.
- Do not put third-party art here unless its license is recorded in `docs/licenses.md`.
- When a new image is supplied in a Codex conversation, import it here so the gallery and the shipped build both include it.
